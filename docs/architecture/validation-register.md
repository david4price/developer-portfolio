# Validation Register (sanitized)

This register tracks the infrastructure assumptions behind the reference deployment. It is a
sanitized mirror: the actual addresses, hostnames, container names, and device identifiers are kept
in a private register outside this repository.

Phase 1 inventory was performed with read-only commands on 2026-11-10/11. Nothing on the host was
changed.
